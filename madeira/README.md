# Сайт авторського туру на Мадейру

Двомовний лендинг (українська / англійська) з формою заявки, яка приходить у Telegram.
Статичні файли: вантажаться на будь-який хостинг або GitHub Pages, сервер не потрібен.

**Сайт зібраний повністю.** Лишилося три речі, які можете зробити тільки ви:
підключити форму, вписати свої дані й обрати хостинг. Нижче — по кроках.

---

## Що зробити вранці: чотири кроки

### Крок 1. Підключити форму до Telegram — 10 хвилин

Форма поки **не працює**: у `content.js` порожнє поле `formEndpoint`, і сайт про це
чесно попереджає замість того, щоб мовчки губити заявки.

1. У Telegram напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → отримайте **токен**.
2. Напишіть [@userinfobot](https://t.me/userinfobot) → отримайте свій **chat_id**.
   Якщо заявки мають бачити кілька менеджерів — створіть групу, додайте туди бота
   і візьміть id групи (починається з `-100`).
3. Напишіть своєму боту будь-яке повідомлення — інакше він не зможе вам відповісти.
4. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** → **Create** →
   **Worker** → назвіть `madeira-form` → **Deploy**.
5. **Edit code** → видаліть шаблон, вставте вміст `worker.js` → **Deploy**.
6. **Settings → Variables and Secrets** → додайте три змінні типу *Secret*:
   `BOT_TOKEN`, `CHAT_ID`, `ALLOW_ORIGIN` (адреса сайту, наприклад `https://globustourniko.com.ua`).
7. Скопіюйте адресу воркера і впишіть у `content.js`:

```js
formEndpoint: 'https://madeira-form.ваш-акаунт.workers.dev',
```

Безкоштовний тариф Cloudflare — 100 000 запитів на добу, для лендингу з запасом.

### Крок 2. Вписати свої дані — 10 хвилин

Усе в одному файлі `content.js`, на початку. Порожній рядок = блок просто не показується.

```js
siteUrl: 'https://ваш-домен',           // потрібна для прев'ю в месенджерах

contacts: {
  phoneUa:   '+380 67 123 45 67',
  phoneUs:   '+1 305 123 4567',
  email:     'hello@globustourniko.com.ua',
  telegram:  'https://t.me/ваш_акаунт',
  whatsapp:  'https://wa.me/380671234567',
  instagram: 'https://instagram.com/ваш_акаунт'
},

legal: {                                 // обов'язково — див. нижче
  ownerUa: 'ФОП Прізвище Ім\'я По батькові',
  ownerEn: 'Individual entrepreneur Name Surname',
  regNo:   '1234567890',
  addressUa: 'м. Київ, вул. ..., буд. ...',
  addressEn: 'Kyiv, ... street, ...',
  email:   'hello@globustourniko.com.ua',
  storageMonths: 24
}
```

**Реквізити — не формальність.** Ви збираєте ім'я і телефон людей з України, це персональні
дані за Законом №2297-VI. Для аудиторії США політика конфіденційності теж обов'язкова
(каліфорнійський CalOPPA). Поки поля порожні, `privacy.html` і `consent.html` показують
червону плашку «документ не готовий до публікації» — щоб ви не запустили сайт без них.

Документи згенеровані за стандартними скелетами: це робочі чернетки, а не юридична
консультація. Перед запуском варто показати їх юристу.

### Крок 3. Опублікувати

**GitHub Pages** — найшвидше і безкоштовно. Settings → Pages → Source: `Deploy from a branch`,
гілка `main`, тека `/ (root)`. Сайт відкриється за адресою
`https://<акаунт>.github.io/globustour-app/madeira/`.

**Свій домен** — завантажте вміст теки `madeira/` у корінь хостингу через FTP або панель.
Обов'язково увімкніть HTTPS: форма збирає персональні дані, без шифрування працювати не повинна.

Після того як домен відомий:
- впишіть його в `content.js → siteUrl`;
- замініть `https://ВАШ-ДОМЕН` у `sitemap.xml` (три місця);
- розкоментуйте рядок `Sitemap:` у `robots.txt`.

### Крок 4. Перевірити з телефона

- [ ] Відправили тестову заявку — прийшла в Telegram.
- [ ] Форма без галочки згоди не відправляється.
- [ ] Політика і згода відкриваються, реквізити в них заповнені, червоної плашки немає.
- [ ] Сайт відкривається по HTTPS.
- [ ] Перемикач мови працює, англійська версія повна.
- [ ] Скинули посилання собі в Telegram — прев'ю показує картку з написом МАДЕЙРА.
- [ ] Тестові заявки видалили з чату менеджерів.

## Фотографії

Поки фото немає, кожен слот показує власний градієнт із підказкою, який знімок туди піде.
Виглядає це як задумана обкладинка, а не як помилка, — сайт можна публікувати вже так.

Коли з'являться знімки: покладіть файли в теку `madeira/` і впишіть імена в `content.js`:

```js
photos: {
  hero:    'madeira.jpg',      // узбережжя або Фуншал згори  (широке, від 1600px)
  funchal: 'funchal.jpg',      // набережна або міський ринок (вертикальне 4:5)
  west:    'porto-moniz.jpg',  // лавові басейни, скляний майданчик
  peak:    'arieiro.jpg',      // Пік Арейро над хмарами
  beach:   'formosa.jpg',      // пляж Прайя-Формоза
  host:    'nico.jpg'          // керівник групи, квадратне
}
```

Хочете сховати підказки «місце для фото» до появи знімків — поставте в `content.js`:

```js
showPhotoHints: false,
```

## Відгуки і блок про автора

Масив `REVIEWS` порожній, тому блока відгуків на сайті **немає взагалі**. Він з'явиться сам,
щойно додасте хоча б один справжній:

```js
window.REVIEWS = [
  {
    name: 'Оксана',
    place: { ua: 'Київ', en: 'Kyiv' },
    photo: '',                       // 'oksana.jpg' — файл поруч з index.html
    text: {
      ua: 'Текст відгуку українською.',
      en: 'The same review in English.'
    }
  }
];
```

Вигаданих відгуків тут бути не повинно: це і обман покупця, і порушення законодавства
про рекламу — і в Україні, і в США (FTC Endorsement Guides).

Так само з блоком про керівника групи (`window.HOST`) і блоком «Про нас» (`window.ABOUT_US`):
поки текст порожній, блока немає.

## Ціна

Зараз блока вартості немає — сторінка веде тільки на заявку. Щоб показати ціну,
впишіть рядок у `content.js`, і блок з'явиться сам:

```js
price: '850 €',
```

---

## Важливе про блок «Входить у вартість»

Список складений із того, що прямо сказано у вашій програмі туру. Що саме входить
у вартість, ви не називали — тому **перевірте перед публікацією**, особливо рядок про
переліт і про дегустації. Це єдине місце на сайті, де може бути неточність.
Правиться в `content.js` → `inclCards` і `inclNoList`.

## Що всередині

```
madeira/
├── index.html            лендинг
├── privacy.html          політика конфіденційності (укр/eng)
├── consent.html          згода на обробку персональних даних (укр/eng)
├── 404.html              сторінка «не знайдено»
├── content.js            ← ЄДИНИЙ ФАЙЛ, ЯКИЙ ВИ ПРАВИТЕ
├── app.js                логіка лендингу
├── legal.js              логіка юридичних сторінок
├── styles.css            оформлення
├── fonts.css + fonts/    Montserrat, підключений з нашого сервера
├── og.png / og-en.png    картка прев'ю для месенджерів і соцмереж
├── apple-touch-icon.png  іконка для екрана телефона
├── robots.txt            дозвіл для пошукових систем
├── sitemap.xml           карта сайту (підставте домен)
├── worker.js             приймач заявок для Cloudflare (розгортається окремо)
└── QA.md                 що саме перевірено
```

Шрифт лежить у репозиторії, а не тягнеться з Google. Це швидше, працює навіть якщо
Google Fonts заблокований у мережі відвідувача, і при відкритті сторінки дані людини
не йдуть стороннім сервісам — так простіше з персональними даними.
Montserrat під ліцензією SIL Open Font License 1.1, копія в `fonts/LICENSE.txt`.

## Мови

- Мова визначається автоматично: українська для браузерів з `uk`, англійська для решти.
- Вибір запам'ятовується в браузері, перемикач — у шапці.
- Пряме посилання: `?lang=ua` або `?lang=en`.
  Для реклами на США ведіть одразу на `.../?lang=en` — тоді сторінка одразу англійською.

## Що свідомо НЕ підключено

- **Аналітика і cookie-банер.** Лічильників немає, рекламні cookie не ставляться,
  тому банер не потрібен. Коли додаватимете GA4 чи Meta Pixel — знадобиться і банер
  згоди, і оновлення політики.
- **Публічна оферта.** На сайті немає оплати, тільки заявка, — оферта не потрібна.
- **Адмінка заявок.** Заявки живуть у Telegram-чаті. Якщо треба база зі статусами,
  експортом і видаленням на запит клієнта — це вже варіант із бекендом.
