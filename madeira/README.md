# Сайт авторського туру на Мадейру

Двомовний лендинг (українська / англійська) з формою заявки, яка приходить у Telegram.
Статичні файли — вантажаться на будь-який хостинг або GitHub Pages, сервер не потрібен.

```
madeira/
├── index.html      лендинг
├── privacy.html    політика конфіденційності (укр/eng)
├── consent.html    згода на обробку персональних даних (укр/eng)
├── styles.css      оформлення
├── content.js      ← ЄДИНИЙ ФАЙЛ, ЯКИЙ ВИ ПРАВИТЕ: тексти, контакти, відгуки
├── app.js          логіка лендингу
├── legal.js        логіка юридичних сторінок
└── worker.js       приймач заявок для Cloudflare (розгортається окремо)
```

## Що треба зробити до запуску

### Крок 1. Підключити форму до Telegram — 10 хвилин

Форма поки **не працює**: у `content.js` порожнє поле `formEndpoint`, і сайт про це чесно
попереджає замість того, щоб мовчки губити заявки.

1. У Telegram напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → отримайте **токен**.
2. Напишіть [@userinfobot](https://t.me/userinfobot) → отримайте свій **chat_id**.
   Якщо заявки мають бачити кілька менеджерів — створіть групу, додайте туди бота
   і візьміть id групи (починається з `-100`).
3. Напишіть своєму боту будь-яке повідомлення — інакше він не зможе вам відповісти.
4. Зайдіть на [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** →
   **Create** → **Worker** → назвіть `madeira-form` → **Deploy**.
5. **Edit code** → видаліть шаблон, вставте вміст `worker.js` із цієї теки → **Deploy**.
6. **Settings → Variables and Secrets** → додайте три змінні типу *Secret*:
   - `BOT_TOKEN` — токен від BotFather
   - `CHAT_ID` — ваш chat_id
   - `ALLOW_ORIGIN` — адреса сайту, наприклад `https://globustourniko.com.ua`
7. Скопіюйте адресу воркера (виду `https://madeira-form.ваш-акаунт.workers.dev`)
   і впишіть її в `content.js`:

```js
formEndpoint: 'https://madeira-form.ваш-акаунт.workers.dev',
```

Cloudflare Workers на безкоштовному тарифі дають 100 000 запитів на добу — для лендингу
це з великим запасом.

### Крок 2. Заповнити контакти

У `content.js`, розділ `contacts`. Порожній рядок = пункт просто не показується на сайті.

```js
contacts: {
  phoneUa:   '+380 67 123 45 67',
  phoneUs:   '+1 305 123 4567',
  email:     'hello@globustourniko.com.ua',
  telegram:  'https://t.me/ваш_акаунт',
  whatsapp:  'https://wa.me/380671234567',
  instagram: 'https://instagram.com/ваш_акаунт'
}
```

### Крок 3. Заповнити реквізити для юридичних сторінок — обов'язково

У `content.js`, розділ `legal`. Поки вони порожні, `privacy.html` і `consent.html`
показують червону плашку «документ не готовий до публікації».

Ви збираєте ім'я і телефон людей з України — це персональні дані за Законом
№2297-VI. Для аудиторії США політика конфіденційності теж обов'язкова (CalOPPA).

```js
legal: {
  ownerUa: 'ФОП Прізвище Ім\'я По батькові',
  ownerEn: 'Individual entrepreneur Name Surname',
  regNo:   '1234567890',
  addressUa: 'м. Київ, вул. ..., буд. ...',
  addressEn: 'Kyiv, ... street, ...',
  email:   'hello@globustourniko.com.ua',
  storageMonths: 24
}
```

Документи згенеровані за стандартними скелетами — це робочі чернетки, а не юридична
консультація. Перед запуском варто показати їх юристу.

### Крок 4. Додати відгуки

У `content.js` масив `REVIEWS` порожній — тому блока відгуків на сайті **немає взагалі**.
Він з'явиться сам, щойно ви додасте хоча б один справжній відгук:

```js
window.REVIEWS = [
  {
    name: 'Оксана',
    place: { ua: 'Київ', en: 'Kyiv' },
    photo: '',                       // 'oksana.jpg' — файл поруч із index.html
    text: {
      ua: 'Текст відгуку українською.',
      en: 'The same review in English.'
    }
  }
];
```

Вигаданих відгуків тут бути не повинно: це і обман покупця, і пряме порушення
законодавства про рекламу — і в Україні, і в США (FTC Endorsement Guides).

### Крок 5. Додати блок про автора туру

У `content.js` об'єкт `HOST`. Поки `name` порожнє — блока немає.

```js
window.HOST = {
  name:  'Ніко',
  role:  { ua: 'керівник групи, Globustour', en: 'group leader, Globustour' },
  quote: { ua: 'Одне-три речення від першої особи.', en: 'One to three sentences.' }
};
```

### Крок 6. Перевірити блок «Що входить у тур» — важливо

Список у `content.js` (`inclYesList` / `inclNoList`) складений із того, що прямо сказано
у програмі туру. Що саме входить у вартість, ви не називали — тому **перевірте цей
список перед публікацією**, особливо рядок про переліт і про дегустації.
Це єдине місце на сайті, де може бути неточність.

### Крок 7. Додати фото

У трьох варіантах оформлення на місцях фотографій стоять заглушки з підписом, яке саме
фото туди піде. Покладіть файли в теку `madeira/` і впишіть імена в `content.js`:

```js
photos: {
  hero:    'madeira.jpg',   // узбережжя або Фуншал згори
  host:    'nico.jpg',      // керівник групи
  funchal: 'funchal.jpg',   // набережна або ринок
  west:    'porto-moniz.jpg',
  peak:    'arieiro.jpg',
  beach:   'formosa.jpg'
}
```

Фото підставляться в усі три варіанти одночасно.

### Крок 8. Ціна — якщо захочете її показати

Зараз блока вартості немає: сторінка веде тільки на заявку. Щоб показати ціну,
впишіть рядок у `content.js` — блок з'явиться сам:

```js
price: '850 €',
```

## Як опублікувати

**GitHub Pages** (найшвидше, безкоштовно). У налаштуваннях репозиторію → **Pages** →
Source: `Deploy from a branch`, гілка `main`, тека `/ (root)`. Сайт відкриється за адресою
`https://<акаунт>.github.io/globustour-app/madeira/`.

**Свій домен.** Завантажте вміст теки `madeira/` у корінь хостингу через FTP або панель
керування. Обов'язково увімкніть HTTPS — форма з персональними даними без нього
працювати не повинна.

## Мови

- Мова визначається автоматично: українська для браузерів з `uk`, англійська для решти.
- Вибір запам'ятовується в браузері, перемикач — у шапці.
- Пряме посилання на конкретну мову: `?lang=ua` або `?lang=en`.
  Зручно для реклами: на аудиторію США ведіть на `.../madeira/?lang=en`.

## Перевірка перед запуском

- [ ] Відправили тестову заявку з телефона — прийшла в Telegram.
- [ ] Форма без галочки згоди не відправляється.
- [ ] Посилання на політику і згоду відкриваються, реквізити в них заповнені.
- [ ] Сайт відкривається по HTTPS.
- [ ] Перевірили обидві мови: перемикач, форма, помилки, юридичні сторінки.
- [ ] Список «Що входить у тур» звірений з реальними умовами.
- [ ] Тестові заявки видалені з чату менеджерів.

## Що свідомо НЕ підключено

- **Аналітика і cookie-банер.** Лічильників немає, рекламні cookie не ставляться,
  тому банер не потрібен. Коли додаватимете GA4 чи Meta Pixel — знадобиться і банер
  згоди, і оновлення політики.
- **Публічна оферта.** На сайті немає оплати, тільки заявка, — оферта не потрібна.
- **Адмінка заявок.** Заявки живуть у Telegram-чаті. Якщо треба база зі статусами,
  експортом і видаленням на запит клієнта — це вже варіант із бекендом.
