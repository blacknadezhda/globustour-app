# Що перевірено

Прогін у справжньому браузері (Chromium) на десктопі 1440×950 і на мобільному 402×874
з двократною щільністю пікселів. Дата перевірки — 21.08.2026.

## Верстка

| Що | Результат |
|---|---|
| Горизонтальний скрол сторінки, десктоп | немає |
| Горизонтальний скрол сторінки, мобільний | немає |
| Шапка на 1000 / 1100 / 1280 / 1440 / 1600 px | пункти меню не переносяться, висота 72px |
| Цілі натискання на мобільному | усі ≥ 44px |
| Кнопка заявки на мобільному | на всю ширину, плюс липка панель після першого екрана |
| Помилок у консолі | немає |

## Чого перевірка НЕ покриває

- **Наскрізний тест із реального телефона по бойовому домену.** Його можна пройти
  тільки після кроків 1–3 з README: заявка → Telegram → відповідь менеджера.
  Поки він не пройдений, запуск не вважається завершеним.
- **Точність блоку «Входить у вартість».** Список складено з програми туру; що саме
  входить у вартість, замовник не називав. Перевіряється вручну перед публікацією.
- **Юридична експертиза документів.** Згенеровані за стандартними скелетами,
  юрист їх не дивився.
